# OneDrive - Cloud File Storage and Sync

## Why This Exists

Many people keep important files scattered across a single PC, a phone, a tablet, and an external drive. Moving between them leads to duplicate copies, outdated versions, and the constant worry that one device holds the only copy of something valuable. **OneDrive** solves this fragmentation by placing files in one cloud location that stays reachable from every connected device.

OneDrive focuses on a clear purpose: cloud file storage and sync that stays understandable. Open OneDrive, choose what to keep in the cloud, and let the sync engine mirror changes without manual copying. If you are tired of wondering which device holds the newest draft, **OneDrive** is for you.

## About OneDrive

OneDrive is a cloud storage service from Microsoft for keeping files, photos, and documents available across devices. OneDrive file sync moves changes between the cloud and each connected machine, while OneDrive backup protects selected folders from local drive failure. OneDrive cloud storage gives home users, students, and offices a single place to store work without carrying physical drives.

OneDrive also connects naturally to Microsoft 365. Documents opened in Word, Excel, or PowerPoint save directly to the cloud, and OneDrive sharing lets colleagues review the same file without email attachments. The result is a steady workflow where storage, sync, and collaboration stay in one place.

## Key Features of OneDrive

- **Cloud File Storage** – Keep documents, photos, and archives in OneDrive cloud storage reachable from any signed-in device.
- **File Sync** – OneDrive file sync mirrors changes between the cloud and each computer without manual copying.
- **Backup Protection** – OneDrive backup covers important folders so a local drive failure does not erase everything.
- **Sharing Controls** – OneDrive sharing lets you send links, set permissions, and collaborate on the same file.
- **Microsoft 365 Connection** – OneDrive Microsoft 365 integration saves Office documents straight to the cloud.
- **Version History** – Restore earlier versions when a file is overwritten or edited by mistake.
- **Cross-Device Access** – View and edit the same files from a PC, phone, or tablet.

## Quick Start with OneDrive

1. **Open OneDrive** – Sign in with your Microsoft account and confirm the sync folder location.
2. **Choose folders** – Select which directories should stay in OneDrive cloud storage.
3. **Enable backup** – Turn on OneDrive backup for documents, photos, and desktop files.
4. **Review sync** – Confirm OneDrive file sync has finished and check the status icons.
5. **Share a file** – Use OneDrive sharing to send a link with the right permissions.
6. **Rescan after changes** – Return to OneDrive after major edits to keep the cloud copy current.
